User Guide ↗

From room design to manufacturing cut list.

Start in Design Studio for a new furniture design, use Panel Geometry or Assembly Builder for specialist component work, and finish in Manufacturing Cutlist. If you already have a drawing, open Cutting List Preparator to import and verify it. Extracted dimensions are suggestions until confirmed; unknown factory specifications stay marked for verification.

Recommended: Design Studio → geometry / assembly → Manufacturing Cutlist

    Accuracy and safetyThere is no verified 1% accuracy claim. DXF import accepts closed, axis-aligned rectangular polylines only and converts units only when $INSUNITS is declared. Other shapes, blocks, nested assemblies and cut-outs may be missed or misread. OCR uses a bounded contrast-enhanced full-page pass and inspects four overlapping detail regions when fewer than three dimension pairs are found; this improves small-label recovery but does not guarantee extraction. Faint marks, handwriting and dimension-to-part relationships remain uncertain and must be checked manually. Sheet demand uses a 2D MaxRects heuristic with a kerf allowance; it is not a machine-validated cutting layout. Confirm drawing scale, unit conversion, part identity, quantities, material, thickness, grain direction and every dimension before production.
