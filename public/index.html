Accuracy and safetyThere is no verified 1% accuracy claim. DXF import accepts closed, axis-aligned rectangular polylines only and converts units only when $INSUNITS is declared. Other shapes, blocks, nested assemblies and cut-outs may be missed or misread. OCR currently uses one bounded contrast-enhanced pass to limit browser memory; faint marks, handwriting and dimension-to-part relationships remain uncertain and must be checked manually. Sheet demand uses a 2D MaxRects heuristic with a kerf allowance; it is not a machine-validated cutting layout. Confirm drawing scale, unit conversion, part identity, quantities, material, thickness, grain direction and every dimension before production.
